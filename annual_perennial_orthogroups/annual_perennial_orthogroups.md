
## Ancestral Reconstruction of Orthogroup Evolution

To investigate the evolutionary history of orthogroups associated with contrasting life-history strategies in *Brachypodium*, ancestral gene-family reconstructions were performed using the software Count (Csurös, 2026), which implements a parsimony-based approach for reconstructing gene-family evolution along a phylogeny. Count infers ancestral family sizes and estimates gain, loss, expansion, and contraction events for each gene family across a user-defined species tree.

The analyses were based on the orthogroup copy-number matrix generated from the pangenome dataset. A total of 117,774 orthogroups had previously been inferred using GET_HOMOLOGUES-EST (Contreras-Moreira et al., 2017; 2022) and represented clusters of homologous sequences across the analysed genomes and subgenomes. The input files for Count included a matrix containing the number of copies detected for each orthogroup in the analysed genomes (`Bsta`, `Bdis`, `Bsyl`, and `Barb`) and subgenomes (`BhybS`, `BhybD`, `BmexP`, and `BmexU`), together with the rooted phylogeny `(((((Barb,Bsyl),(Bdis,BhybD)),(BhybS,Bsta)),BmexU),BmexP)` inferred using BEAST2, where `BmexP` represents the most basal lineage in the dataset.

**Definition of Life-History-Associated Orthogroups**

Orthogroups were previously classified according to their presence/absence distribution among annual and perennial taxa.

Annual-associated orthogroups were defined as those present in both annual diploid species (`Bdis` and `Bsta`) and additionally detected in at least one of the two subgenomes of the allotetraploid *B. hybridum* (`BhybD` and/or `BhybS`), while being absent from all perennial genomes and subgenomes (`Barb`, `Bsyl`, `BmexP`, and `BmexU`).

Perennial-associated orthogroups were defined as those present in both perennial diploid species (`Barb` and `Bsyl`) and additionally detected in at least one of the two *B. mexicanum* subgenomes (`BmexP` and/or `BmexU`), while being absent from all annual genomes and subgenomes (`Bdis`, `Bsta`, `BhybD`, and `BhybS`).

Additional orthogroup categories included:

- **Core_species**: present in all diploid species and in at least one subgenome of each allotetraploid species (`BhybD` and/or `BhybS`; `BmexP` and/or `BmexU`).
- **Core_subgenomic**: present in all genomes and subgenomes.
- **Annual_Bmex**: present in the annual species `Bdis` and `Bsta`, present in at least one *B. hybridum* subgenome (`BhybD` and/or `BhybS`) and at least one *B. mexicanum* subgenome (`BmexP` and/or `BmexU`), and absent from the remaining perennial species.

Using the files all.p2o.csv and all.pfam generated by GET_HOMOLOGUES-EST with the -D option, together with the in-house script `_match_p2o_pfam.sh`, orthogroup/CDS identifiers were linked to Pfam identifiers and annotations. This step generated the output file `p2o_pfam_match_output.tab`.
The Pfam annotation was subsequently incorporated into the pangenome matrix using the in-house script _merge_pangenome_pfam.sh, generating `pangenome_matrix_t0.tr_pfam.tab`.
For Count analyses, only the orthogroup identifier column and the sequence-copy-number columns corresponding to each species and subgenome were retained, generating `Count_input_pangenome_matrix_t0.tr.tab`
```
cut -f1-9,12,13 pangenome_matrix_t0.tr_pfam.tab \
> Count_input_pangenome_matrix_t0.tr.tab
```
The `script _filter_pangenome_groups_v2.sh` was then used to filter orthogroups according to the presence/absence combinations corresponding to the annuality and perenniality patterns under investigation.

**Ancestral Reconstruction of Evolution Associated with Annual and Perennial Habits**

Count Software

The analyses used as input the orthogroup sequence-copy-number matrix for each species and subgenome (`Count_input_pangenome_matrix_t0.tr.tab`) together with the BEAST2-derived phylogeny (`phylogeny_BEAST2.newick`).

The main Count output file was `output_count_ALL_families_parsimony.tab`
This file was subsequently filtered and interrogated using the scripts and procedures described below.

**Parsimony-Based Ancestral Reconstruction**

Orthogroup evolution was reconstructed using the Wagner parsimony framework implemented in Count. For each orthogroup, Count estimated the reconstructed family size at terminal and ancestral nodes, the number of inferred gains, losses, expansions, and contractions.

Internal nodes were designated according to the Count output as:

| Node | Description |
|------|-------------|
| U14 | Root |
| U13 | Ancestor of `BmexU` and crown *Brachypodium* |
| U12 | Ancestor of `Barb`, `Bsyl`, `Bdis`, `BhybD`, `BhybS`, and `Bsta` |
| U10 | Ancestor of `((Barb,Bsyl),(Bdis,BhybD))` |
| U11 | Ancestor of `(BhybS,Bsta)` |
| U9 | Ancestor of `(Bdis,BhybD)` |
| U8 | Ancestor of `(Barb,Bsyl)` |

(see `Supplementary Figure 10`).

**Determination of the Earliest Reconstructed Ancestral Node**

To facilitate interpretation of orthogroup histories, a series of custom Python scripts were developed.

The script `_extract_ancestral_states.py` extracted reconstructed ancestral family sizes from Count outputs, whereas `_classify_histories.py` and `_origin_node.py` identified the earliest ancestral node in which an orthogroup was reconstructed as present.

For each orthogroup, ancestral family sizes (n) were scanned sequentially from the root towards younger nodes (U14 → U13 → U12 → U10 → U11 → U9 → U8). The first node exhibiting a reconstructed copy number greater than zero (n > 0) was designated as the Origin_Node.

This procedure does not infer the true evolutionary origin of a family. Rather, it identifies the deepest node within the reconstructed parsimony scenario at which the orthogroup is inferred to be present.

**Quantification of Gain, Loss, Expansion, and Contraction Patterns**

The scripts `_summary_stats.py`, `_origin_summary.py`, and `_origin_event_summary.py` were used to summarise the distribution of gain, loss, expansion, and contraction events associated with each Origin_Node category.

For every ancestral node, the following statistics were calculated:

- Number of orthogroups.
- Mean number of gains.
- Mean number of losses.
- Mean number of expansions.
- Mean number of contractions.
- Number of families exhibiting at least one gain.
- Number of families exhibiting at least one loss.
- Number of families exhibiting at least one expansion.
- Number of families exhibiting at least one contraction.

An expansion or contraction event was considered present whenever Count reconstructed at least one expansion (Expansions > 0) or contraction (Contractions > 0) event for a given orthogroup.

Similarly, gain and loss events were considered present whenever Count inferred at least one gain (Gains > 0) or loss (Losses > 0) event during the reconstructed history of the orthogroup.

Identification of Orthogroups Showing Ancestral Retention and Secondary Losses

Orthogroups reconstructed in deep ancestral nodes were further investigated using the script `_ancestral_loss_analysis.py`.

Families were retained for subsequent analyses when:
```
Origin_Node ∈ {U12, U13, U14} and Losses > 0
```
These orthogroups were considered candidates for ancestrally present families whose present-day taxonomic distributions could be explained by lineage-specific secondary losses.

**Classification of Evolutionary Mechanisms**

To facilitate biological interpretation of orthogroup histories, the script `_evolutionary_mechanisms.py` assigned each family to a heuristic evolutionary category based on its reconstructed Origin_Node and event profile.

Orthogroups were classified as:

- `Ancestral_retention_plus_losses` when `Origin_Node ∈ {U12, U13, U14} and Losses > 0`
These families were interpreted as ancestrally present orthogroups whose current restricted distribution is consistent with differential retention and secondary gene-family losses.

- `Derived_gain` when `Origin_Node ∈ {U8, U9, U10, U11}
indicating orthogroups associated with more recent lineage-specific evolutionary histories.

Families exhibiting at least one expansion event:
- `Expansions > 0` received the suffix `_with_expansion`yielding the categories `Derived_gain_with_expansion` and `Ancestral_retention_plus_losses_with_expansion`

Importantly, the evolutionary mechanisms described above (e.g. Ancestral_retention_plus_losses and Derived_gain) were not generated directly by Count. Instead, they represent heuristic categories derived from the Count parsimony output through custom in-house Python scripts based on combinations of reconstructed ancestral presence, gain/loss events, and expansion patterns. These categories were designed to provide a biologically interpretable framework for comparing orthogroup histories across annual and perennial lineages.

The tabular outputs generated are available in the worksheets of the Excel file `Table_gain_loss_ancestral.xlsx`
